# CYBERTRACE

### Don’t just learn cybersecurity. Investigate it.

CYBERTRACE is a browser-based, gamified cybersecurity investigation platform designed to introduce users to real-world security operations concepts through interactive incident investigations.

Instead of solving traditional CTF-style challenges or playing as an attacker, the user takes the role of a **Security Analyst** and investigates a simulated security incident by reviewing evidence, correlating clues, reconstructing an attack timeline, learning relevant MITRE ATT&CK techniques, making incident-response decisions, and producing a final incident report.

## 📌 Project Overview

Cybersecurity concepts can be difficult to understand when they are presented only through theory.

CYBERTRACE turns common cybersecurity investigation concepts into a short, guided interactive experience.
