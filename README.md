# CYBERTRACE

### Don’t just learn cybersecurity. Investigate it.

CYBERTRACE is a browser-based, gamified cybersecurity investigation platform where users take the role of a **Security Analyst** and investigate simulated cyber incidents.

Instead of playing as a hacker or solving traditional CTF challenges, users follow a simplified SOC investigation workflow:

**Alert → Evidence → Correlate → Timeline → MITRE ATT&CK → Response → Report → Debrief**

## 🎯 Purpose

CYBERTRACE makes cybersecurity concepts easier and more engaging by turning them into an interactive investigation.

Users learn about:

- Phishing and credential compromise
- Authentication and endpoint activity
- PowerShell abuse
- Command & Control
- Data exfiltration
- Threat intelligence
- Evidence correlation
- Incident response
- MITRE ATT&CK

## 🔎 Case #001 — The 2:17 AM Alert

The first investigation takes place at the fictional organization **Nimbus Logistics**.

The player investigates a suspicious incident involving:

**Phishing → Credential Theft → VPN Access → Mailbox Access → PowerShell → C2 → Data Transfer**

The case includes realistic-style evidence such as emails, authentication logs, endpoint activity, network events, threat intelligence, and benign false positives.

## 🎮 Key Features

- Guided investigation
- Interactive evidence
- Clue correlation
- Timeline reconstruction
- MITRE ATT&CK learning
- Incident-response decisions
- Analyst notes
- Optional hints
- Final incident report
- Achievements and in-game scoring
- Beginner-friendly explanations

The scoring system represents **game progress only** and is not a professional cybersecurity assessment.

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

The current MVP is completely client-side and requires no account, backend, or database.
